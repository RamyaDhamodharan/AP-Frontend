# AP Frontend

React 19 + TypeScript + Vite starter. Includes TanStack Query/Router, Axios, React Hook Form and Zod dependencies.

## Windows local run
1. Install Node.js LTS.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the URL printed by Vite (normally `http://localhost:5173`).

Current page is a scaffold placeholder. Login, upload, bills list, verify/edit, command center, audit and admin screens are not implemented. Tailwind/shadcn setup should be added as part of the UI implementation.
